Weapon stat response curves

Vary one effective main attribute while keeping the default mounted build, other main attributes and calibration fixed. These are model responses, not measured Global-client performance. The 0–150 range is exploratory; it does not assert that every point is attainable.

Charts show each metric relative to this weapon/mode's default (100%). That is not a combined performance score: lower recoil/time/spread is favorable, while higher movement speed/hold duration is favorable. Main attribute points can differ from displayed panel points. Click or hover on a chart to inspect raw values.
